# Against Time Contest 2021

## About
This repository contains a collection of Python solutions developed for the "Against Time Contest 2021," hosted by the Coding Club of NISER. The project serves as a snapshot of competitive programming efforts, focusing on the rapid implementation of algorithmic logic and the ability to translate specific problem constraints into working code under time pressure.

## Technical Details
The codebase consists of five independent Python scripts, each solving a distinct computational problem. The technical implementations include:

- **String Analysis**: Using built-in Python string methods for frequency counting.
- **Conditional Arithmetic**: Calculation of allowances (HRA and DA) based on salary thresholds to derive a total sum.
- **String Transformation**: Element-wise comparison of two input strings to generate a third sequence based on matching characters.
- **Sliding Window**: Implementation of a sliding window approach to find the maximum sum of a contiguous subarray of length $k$.
- **Modular Arithmetic**: Logic checks using the modulo operator to determine properties of divisibility and congruence, specifically verifying if $n \pmod k \neq 0$ or if $x \equiv y \pmod k$.

## Execution
Each script is designed to run in a Python 3 environment and accepts input via standard input (stdin).

To execute a specific solution:
```bash
python <script_number>.py
```
Example:
```bash
python 1.py
```
After running the script, provide the required input values as specified by the problem constraints.
